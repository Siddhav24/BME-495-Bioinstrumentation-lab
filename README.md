# BME-495 Bioinstrumentation Lab

This repository contains LabVIEW projects and VIs developed for BME-495 Bioinstrumentation.

---

## Lab 1: Bioinstrumentation Amplifier Characteristics
Objectives: 
• Use the NI CompactDAQ system (NI cDAQ-9174 chassis + NI 9215 analog input module) and
LabView software to test the operation of the ETH-256 Instrumentation amplifier.
• Measure characteristic performance of the amplifier (baseline noise, gain error, saturation
limit, and filter performance) relative to the manufacturer’s specification.
• Collect your measurement data to a file for data analysis

## Lab 2: The Electrocardiogram (ECG)
Objectives:
• Examine the adequate sampling rate for accurate representation of ECG analog signal.
• Characterize and quantify the PQRST waveform and statistically analyze the data across
subjects and compare them to the supplied standard values.
• Analyze and quantify the electrode-skin and motion artifacts for each team member.
